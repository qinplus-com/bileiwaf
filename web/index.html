产品简介

壁垒WAF（BILEI Web Application Firewall）部署于业务流量入口，对全部入站请求进行深度检测：先经快速特征预筛剔除正常流量，再命中规则引擎与 AI 双通道完成攻击判定，恶意请求实时阻断并记录审计日志，正常请求透明转发至后端源站。

支持检测模式（仅告警）与阻断模式灵活切换，防护策略按站点粒度独立配置，业务零侵入接入。
