功能总览

🎯 规则检测引擎SQL 注入 / XSS / 命令注入 / 路径穿越 / XXE / SSRF 等多类攻击规则，POSIX 正则匹配，支持热加载
🧠 AI 智能检测机器学习模型（孤立森林 / 随机森林 / 自编码器）与规则引擎混合双擎检测
🌊 CC 攻击防护基于滑动时间窗的 IP 请求频率限制，超限自动封禁，支持白名单豁免
🚫 IP 黑白名单IP 级访问控制，秒级生效，扫描器 / 爬虫 UA 特征识别
🔒 SSL/TLS 卸载HTTPS 终结与证书管理，支持 Let's Encrypt 自动签发与续期
🌐 多站点防护一台 WAF 同时代理防护多个域名，站点独立配置与日志
🖥️ 系统监控大屏内置监控大屏：攻击态势总览、实时攻击事件、TOP 源与规则统计可视化
📋 多维日志审计攻击日志 / 访问日志 / 审计日志 / 错误日志，完整请求上下文记录
⚡ 高性能架构C 语言多线程 + 连接池 + epoll 事件驱动，低延迟反向代理
🛠 三种工作模式学习模式（只告警）→ 检测模式（告警+记录）→ 阻断模式（实时拦截）
🔌 协议完整性校验HTTP 协议合规、异常请求识别、API 防护、WebSocket 代理支持
🌍 GeoIP 地域封禁按国家 / 地维度限制访问来源（内置 GeoIP 模块）
